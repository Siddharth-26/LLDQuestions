ATM Machine Design :
Requirements :
- withdraw Money
- check Balance
- verify Card
- verify PIN
- should be able to cancel the transaction in between.

- State : insertCard(CardNumber), insertPin(Pin), chooseOperation(OPERATION.CHECK_BALANCE/OPERATION.WITHDRAW), cancelTransaction(), checkBalance(), withdrawAmount(), dispenseAmount()
- IdleState :
- PinInsertionState :
- ChooseOperationState :
- CheckBalanceState :
- WithdrawMoneyState :
- DispenseAmountState :
