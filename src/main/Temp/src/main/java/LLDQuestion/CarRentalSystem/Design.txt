Requirements :
- User should be able to select the Pickup Point and the date range and should be able to also specify the filters like budget and vehicle type
they should be able to see the list of the vehicles available during this particular date range and of the specified filters.
- Users should be able to reserve a particular vehicle , and change or modify these reservations
- User should be able to pay with different type of modes. The price calculations should be extensible.
- There should be audit logs of payments and transactions
- There should be logs of the transactions that are being done when the reservations that happen.
